# Alireza Torabi · Portfolio

A desktop-style portfolio. Plain HTML, CSS and JavaScript, no build step.

## Edit content
Everything you'd want to change lives in `content.js`:
- `SITE.intro` for the opening text and tags
- `PROJECTS` to add or edit projects (screenshots go in `assets/projects/`)
- `CASE_STUDIES` to add case studies (copy an entry; every section is optional)
- `CERTIFICATES` (add a `verifyUrl` to show a "Verify credential" link)
- `RESUME` for the resume window; replace `assets/Alireza-Torabi-Resume.pdf` to update the download

## Deep links
Every window has its own link, e.g. `/#/projects`, `/#/project/backpack`, `/#/case/ramis-mvp`, `/#/certificates`, `/#/resume`, `/#/contact`.

## Deploy
Push these files to a repo named `AlirezaTomama.github.io` (main branch, root). GitHub Pages serves it at https://alirezatomama.github.io/
